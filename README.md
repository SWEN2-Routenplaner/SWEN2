# SWEN2

## Startup

1. Start the docker containers using ''docker compose up -d'' to initiate the the database and the authenication service. This can take a few minutes.
2. Navigate into the backend folder and start the backend using ''./mvnw.cmd spring-boot:run'' on windows and ''./mvnw spring-boot:run'' on linux.
3. Navigate to the frontend folder and start the frontend using ''npm install && npm run start''.
4. Go to localhost:4200 to use the website.
